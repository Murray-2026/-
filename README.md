# 隔离器售前文档生成系统

> Isolator Pre-Sales Document Generator

专业的制药隔离器售前文档生成工具，支持 URS 逐条回复和快速报价单生成。

## ✨ 功能特性

- 📝 **URS智能解析** — 粘贴客户URS/询盘文档，自动识别设备类型和关键需求
- 📋 **URS逐条回复** — 自动生成供应商逐条回复，含技术说明和法规依据
- 💰 **快速报价单** — 技术方案概要 + 高低配配置清单 + 报价明细
- 🏭 **4种隔离器** — 单体无菌隔离器 / VHP传递窗 / 整线隔离器 / 单体负压隔离器
- 🌍 **5大法规体系** — 中国GMP / FDA 21 CFR / EU GMP Annex / WHO GMP / PIC/S
- 💾 **数据持久化** — 历史报价单、客户档案、模板库（localStorage本地存储）
- 📱 **移动端适配** — 手机、平板、电脑均可使用
- 📤 **导出功能** — 支持复制全文、打印/导出PDF

## 🚀 使用方法

### 在线使用
直接访问：[https://murray-2026.github.io/-/](https://murray-2026.github.io/-/)

### 本地使用
1. 下载或克隆本仓库
2. 用浏览器打开 `index.html` 即可使用，无需安装任何依赖

### 操作流程
1. 在左侧粘贴客户的 URS 文档或询盘内容
2. 点击"智能解析"自动识别设备类型和关键参数
3. 确认/修正解析结果，选择预算级别
4. 点击"生成文档"获得 URS 逐条回复和快速报价单
5. 可保存为报价单、模板，随时复用
